# Phone-only build

1. Create a GitHub repository named SecurePay.
2. Upload all files from this project.
3. Open the repository's Actions tab.
4. Select "Build SecurePay APK".
5. Tap "Run workflow".
6. When it finishes, open the workflow run.
7. Download the "SecurePay-debug" artifact.
8. Extract it and install app-debug.apk.

The installed APK does not require Python, Flask, Termux, AndroidIDE, or a PC.
